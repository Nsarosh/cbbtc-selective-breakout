A deterministic, long-only cbBTC volatility-breakout momentum bot. It filters flat bars and thin liquidity, scales positions with signal strength, manages exits with a trailing stop and take-profit, and enforces an 18% equity drawdown kill switch. Built for make.fun's 24-hour paper-trading race; it never places real trades.

## Run it
